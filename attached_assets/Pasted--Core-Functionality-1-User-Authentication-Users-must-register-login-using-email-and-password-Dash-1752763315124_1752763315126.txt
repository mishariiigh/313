 Core Functionality
1. User Authentication
Users must register/login using email and password.

Dashboard showing number of purchased games remaining.

Purchase history (optional Phase 2).

2. Game Model
Each game is a set of 36 non-multiple-choice questions.

Questions appear one at a time, and the user manually reveals the answer to the group.

Used for facilitating discussions or competitions in-person.

Each game is "consumed" when played — it cannot be repeated (locked after use).

3. Question Structure
No answer choices. Instead, the question is displayed with a “Reveal Answer” button.

After clicking “Reveal,” the correct answer (and optional explanation) is shown.

Optional hint can be displayed before revealing the answer.

4. Question Categories
Each game pulls 36 random questions across:

التاريخ (History)

الجغرافيا (Geography)

الدين (Islamic Knowledge)

الرياضة (Sports)

الثقافة العامة (General Culture)

العلوم (Science)

Each question is tagged with a difficulty level: سهل – متوسط – صعب
(12 easy, 12 medium, 12 hard per game).

🛒 Game Purchase System
Users purchase credits or game packs (e.g., 1 game = $1.99, 5 games = $8.99).

After purchase, games are added to their account.

Games can only be played once; after use, they’re marked as “Used”.

Integration with Stripe or local payment gateway (KNet if in Kuwait).

📱 User Flow
User signs in.

Sees remaining purchased games.

Clicks “Start New Game” → system generates 36-question session.

Question screen shows:

Question (text)

Button: “Show Hint” (optional)

Button: “Reveal Answer”

Button: “Next Question”

Final screen says “Game Finished” with option to return to dashboard.

That game session is marked as “used.”

📂 Admin Panel
Admin login with full control to:

Add/edit/delete questions

Assign difficulty and category

Add hint and explanation fields

Track:

Number of users

Games played

Most used categories (optional analytics)
